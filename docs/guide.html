Hexcrawl Forge

Rolls a whole hexcrawl region from your table library, for Shadowdark now and Old-School Essentials later. Every line it writes cites its book and page.

Two ways to use it

Web pagehttps://renangrossi.github.io/hexgen/ — runs in the browser, nothing to install.
Command lineThe hexgen folder. Makes HTML, Markdown, JSON and PDF files in out/.

The web page

Region tab

SystemShadowdark (Western Reaches travel, core encounter tables) or OSE (Referee’s Book encounter tables, real monster names).
Width, HeightMap size in hexes. Each hex is 6 miles. 16×12 is a good start.
ClimateTemperate, cold (glaciers), hot (jungle), dry (desert).
Sea onWhich map edges are coast. Tick none for a landlocked region.
SeedThe number every roll comes from. Same seed and settings, same region.
NameOptional. Left blank, the region name is rolled and matched to its main terrain.
Generate regionRolls the region for the seed in the box. Pressed again unchanged, it gives the same region.
New seedPuts a random seed in the box and rolls a new region.

Tap a hex on the map to jump to its entry. Write down the seed of a region you want to keep.

Other tabs

Settlement rolls one place of any size, with an optional port. Ships rolls ships. Any table searches all 982 tables by id or title, rolls one several times, or shows it whole.

What a region contains

MapTerrain, rivers, lakes, coast, roads between settlements; ruins ⌂ and lairs ☠ marked.
SettlementsSpectacular Settlements’ full procedure for the size; WWN reason, ruler, problem, a local who needs the PCs, what it offers, Community tags; Perilous Wilds feature and problem; Overland Hexcrawl districts, shops, tavern, events, rumors; street encounters by district; NPCs, hirelings, trade jobs, temple.
PortsHarbor, who rules the docks, trouble on the quay, passage and captain, ships at anchor.
ShipsOf Ships & the Sea type, purpose, attitude, crew, name, disposition; hull state, hold, crew mood, a crew member, her story; boat stats.
Hex keyHazards, lore, situations, creatures, points of interest, landmarks, discoveries, WWN wilderness tags.
Ruins, lairsWWN ruin chapter and tags; Perilous Wilds size, themes, builder, purpose, cause of ruin; 3–6 keyed areas with dressing, exits, creatures (SD cave/tunnel/tomb/ruin or OSE dungeon levels), traps, hazards, enigmas, sealed chambers; WWN valuables. Lairs get WWN complications and sometimes a unique monster.
RealmGovernment, history, people, neighbors and building style (WWN); two faiths and a cult; great terrain features.
Adventures, questsThree WWN adventure seeds, family lore for the PCs, and quests in every settlement (OH quest generator with WWN hooks, investigation and negotiation).
PowersTwo WWN courts, two OH factions, and how each pair stands.
Play tablesTravel and encounter rules, daily weather, every encounter table the map needs, dungeon encounters, road encounters, sea weather, wind, events, denizens, Of Ships encounters and hazards, travel misfortune, quest tables, downtime, Western Reaches rumors.

Command line

cd "Shadowdark/My Projects/hexgen"
python3 -m hexgen region                       # Shadowdark, 16×12, sea west
python3 -m hexgen --seed 7 region --system ose --climate cold --sea n --size 20x14 --pdf
python3 -m hexgen settlement --kind city --coastal
python3 -m hexgen ship --count 3
python3 -m hexgen roll pw.discovery --times 5
python3 -m hexgen list wwn.p183                # browse table ids
make test                                       # every table rolls, both systems render

Every table the generator uses

Adding books and updating

List a book in sources.yaml, then run make data: it extracts the die tables from the PDF, gives each an id <book>.p<page>.<title>, and checks they all roll. Tables with gaps are marked for review and skipped. Fix a mangled table in data/hand/overrides.yaml.

After changing tables, run python3 tools/export_web.py, commit and push to main; GitHub Pages redeploys the web page.
